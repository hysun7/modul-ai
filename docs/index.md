# Modul Praktikum Mata Kuliah Kecerdasan Buatan

Selamat datang di **Modul Praktikum Mata Kuliah Kecerdasan Buatan**.

Website ini berisi panduan praktikum yang disusun bertahap mulai dari penggunaan Google Colab, pengolahan data, machine learning, cross-validation, hingga klasifikasi citra menggunakan neural network.

!!! info "Petunjuk"
    Pilih modul melalui menu navigasi di sebelah kiri. Setiap modul dapat dilengkapi dengan tujuan, kode program, latihan, dan tugas praktikum.
