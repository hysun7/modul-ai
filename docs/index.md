# Modul Praktikum Mata Kuliah Kecerdasan Buatan

Selamat datang di **Modul Praktikum Mata Kuliah Kecerdasan Buatan**.

Website ini berisi panduan praktikum yang disusun bertahap mulai dari penggunaan Google Colab, pengolahan data, machine learning, cross-validation, hingga klasifikasi citra menggunakan neural network.

!!! info "Petunjuk"
    Pilih modul melalui menu navigasi di sebelah kiri. Setiap modul dapat dilengkapi dengan tujuan, kode program, latihan, dan tugas praktikum.

## Daftar Modul

1. **Modul 01:** Menggunakan Google Colab
2. **Modul 02:** Membaca Data
3. **Modul 03:** Membuat Model Machine Learning Menggunakan Random Forest
4. **Modul 04:** Membuat Model Machine Learning Menggunakan Random Forest dengan Data Numerikal dan Kategorikal
5. **Modul 05:** Stratified K-Fold Cross Validation
6. **Modul 06:** Stratified K-Fold Cross Validation dengan K-Nearest Neighbors (KNN)
7. **Modul 07:** Stratified K-Fold Cross Validation dengan Support Vector Machine (SVM)
8. **Modul 08:** Stratified K-Fold Cross Validation dengan Neural Network (MLP)
9. **Modul 09:** Klasifikasi Gambar Dataset MNIST dengan Multi Layer Perceptron (MLP)
10. **Modul 10:** Klasifikasi Gambar Dataset MNIST dengan Convolutional Neural Network (CNN)
11. **Modul 11:** Pengolahan Citra Digital
12. **Modul 12:** Klasifikasi Citra dengan VGG16 dan 5-Fold Cross Validation

## Format Praktikum

Setiap modul dapat menggunakan struktur berikut:

- Tujuan praktikum
- Persiapan
- Langkah praktikum
- Kode Python
- Analisis hasil
- Tugas praktikum
- Ketentuan pengumpulan
